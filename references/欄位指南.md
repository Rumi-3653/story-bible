# 欄位指南 — 每個欄位：誰吃它、格式、範例、匯出對照

> 建卡前必讀，填好的成品看 `examples/還傘/`。欄位命名沿用作者既有創作語彙，不另造新詞：novel-analysis 五鏡頭與 storytelling-coach 是作者另外兩支 skill（不在本 repo，此處只借用其術語）；emotion-shot-pipeline 是另一個公開 repo（github.com/Rumi-3653/emotion-shot-pipeline），schema 在它的 core/schema.py。
>
> **格式約定**（`scripts/bible.py` 靠這些解析）：欄位寫成 `- **欄位名**：值`（欄位名後可夾括號說明，全形/半形冒號都行）；多行內容（關係網、條列式性格）寫成縮排兩格的子項；整格包在全形括號裡（如「（待補）」）視為未填。

## 一、角色卡欄位

### A. 基本

| 欄位 | 誰吃它 | 格式與說明 |
|---|---|---|
| 名字 | 全部 | 短名，同時是檔名與 relations 的 key。生成平台若有 Element/@tag 名（如 Seedance 的 @角色名、Kling 的 Element 名），一併記 |
| IP/系列 | 索引 | 對應 `library/<IP名>/` 資料夾名（本 repo 只附範本與 examples，不附作者的私人卡） |
| 年齡 | 編劇/生圖 | 整數。定調用詞、體力狀態、社會位置（emotion-shot-pipeline 必填欄） |
| 身分 | 編劇 | 一句話：職業/處境 |
| 敘事功能 | 編劇/邏輯審稿 | 主角/鏡像/催化劑/阻力/反題立場…＋一句話說明此角色扣住全片哪個戲劇問題。審稿用它抓喧賓奪主 |
| 原型/經典錨 | 編劇 | 對應哪個古典文本/神話原型（普羅米修斯/莊子/哪吒…），出處要真實不可杜撰（novel-analysis 紀律） |
| 母題 | 編劇 | 犧牲/成長/背叛/回歸/破繭…及其新變奏 |

### B. 視覺層（生圖用——這一層的文字會直接進 prompt）

| 欄位 | 誰吃它 | 格式與說明 |
|---|---|---|
| 外貌（appearance） | 生圖/分鏡 | 長文描述，**只寫恆定可視特徵**：2-3 個五官定錨、體態、髮型髮色、服裝（顏色+材質+剪裁）、一項標誌性細節（袖口顏料漬/薄繭）。會逐鏡變化的道具狀態→寫進 appearance_note 指向的 props 檔 |
| appearance_note | 人（防呆） | 「永不注入 prompt」的備註欄：道具外觀存放處、不登場角色不可生成畫面等提醒 |
| 角色鎖逐字句 | 生圖 | 實測定案的固定句組（開頭句/風格結尾句/避免子句），**引用時一字不差**。含 English 鏡像（給 Kling/Runway/MJ） |
| 參考圖 | 生圖（鎖臉命門） | 路徑清單＋每張用途（主參考/臉部特寫/側面）。各平台鎖臉機制：Kling Omni 掛 Element、MJ `--cref --cw 100`、ChatGPT/Nano Banana 附圖明講「臉不要變」、Seedream/Flux Kontext 吃參考圖後只描述動作 |
| 最佳平台 | 生圖 | 實測過的平台＋流程要點（例：Kling 走 Omni 頁不走 Video Generation 頁） |
| 色票/風格錨 | 生圖/分鏡 | 主色調 token（冷藍主調×暖橘裂隙光）；與世界觀卡的美術基調呼應 |

### C. 敘事層（編劇/審稿用）

| 欄位 | 誰吃它 | 格式與說明 |
|---|---|---|
| 性格（personality） | 編劇寫台詞語氣與內心OS；邏輯審稿逐鏡抓 OOC | 短句羅列**行為模式與心理防衛機制**（「話少、細心」「失望時不吵不鬧，只是把心再關小一格」），不是形容詞堆疊 |
| 背景故事（background） | 編劇找動機源頭；邏輯審稿查因果、抓 Deus ex machina | 長文段落，含具體物件/事件細節以利鏡頭呼應（「那把淺灰藍長柄傘是離鄉前在老家鎮上買的，陪了她三年」） |
| 關係網（relations） | 編劇定張力來源與台詞對象；審稿核對互動 | **dict**：key=對象（可以是不入鏡的畫外角色或壓力來源），value=關係描述 |
| 弧線（arc） | 編劇保證最後一顆鏡頭兌現它；情緒審稿比對情緒轉折 | 「從…走到…」完整句，具體到終點的視覺/行動證據 |
| 主導情緒/底噪情緒 | 情緒審稿/配樂 | 各一詞。主導=主色調情緒，底噪=底下一直沒散的。比籠統「個性」精準（novel-analysis §⑤） |
| 情緒詞彙表 | emotion-shot-pipeline 匯出 | 該管線 emotion 欄只吃 14 詞：平靜、溫暖、期待、喜悅、好奇、緊張、恐懼、悲傷、憤怒、孤獨、釋然、敬畏、決絕、失落 |

### D. 聲演層（配音/對白用）

| 欄位 | 誰吃它 | 格式與說明 |
|---|---|---|
| 語氣人設 | 編劇寫對白；配音選 preset | 一句定位（「溫柔但清醒的朋友，不是老師」）＋語速感＋敢留白程度＋用語習慣（少說「你應該」，多說「你可以試試」） |
| 語癖/口頭禪 | 編劇 | 固定句式、慣用詞、句長偏好 |
| 對白樣本 | 編劇/配音試聽 | 3-5 句最能代表此角色的台詞（含固定片頭片尾句如有） |
| OS vs 台詞落差 | 編劇/情緒審稿 | 這角色「想的」和「說的」差在哪——有落差才有戲（emotion-shot-pipeline inner_os 紀律） |
| engine | 配音 | edge-tts（預設）/ Gemini 3.8 Flash TTS（雲端預製音色＋一句話風格，有演技；voice 填音色名如 Sulafat，style 填語氣人設）/ F5-TTS 本機克隆 / ElevenLabs v3 / Minimax。**F5-TTS 綁定使用者本人聲音，虛構角色不可用**，除非另建合法授權參考音 |
| voice | 配音 | edge-tts ShortName（zh-TW-HsiaoChenNeural…）或 ElevenLabs 挑選準則/voice ID |
| base rate/pitch/volume | 配音 | 位移字串。**負值必用等號寫法** `--rate=-24%`（空格會被 argparse 誤判） |
| 情緒位移覆寫 | 配音 | 只在偏離 tts_expressive.py 內建九款 preset（平穩/低語/沉/懸念/感嘆/緊張/激動/高潮/收尾）時才填，格式同配音譜 `【高潮 rate=+20% pitch=+12Hz vol=+18%】` |
| 唸法校正表 | 配音（前處理） | edge-tts 不吃 SSML；破音字/專名/數字用同音字改寫。一行一組「原字→替換字」 |
| 混音預設 | 配音 | mix.py 旗標組合（--vo-gain/--music-gain/--duck-ratio/--vo-delay/--tail…），記此角色/系列慣用值 |
| 定案試聽檔 | 人耳比對 | 聲線定案成品音檔路徑，下次生成前比對音色語速有沒有跑掉 |
| 使用限制 | 合規 | 僅限哪個系列使用、克隆授權註記 |

### E. 一致性與版本

| 欄位 | 說明 |
|---|---|
| 出場紀錄 | 哪些 EP/專案出現過＋各集限定的狀態變化（EP5 閃回幼年版…） |
| 原始出處 | 匯入來源檔路徑（腳本角色卡節/json/程式碼行號）——正本雖在本庫，但出處可考 |
| 版本紀錄 | 日期＋改了什麼。每次改卡加一行 |

## 二、場景卡欄位

| 欄位 | 誰吃它 | 說明 |
|---|---|---|
| 核心元素 | 生圖 | 3-6 個具體可視元素（蒸籠水蒸氣/紅燈籠/濕漉街面） |
| 光線/時間/天氣 | 生圖/情緒 | 光源方向+硬柔+色溫；讓光隨情緒走 |
| 色票 | 生圖 | 主色與 HEX（如有定案） |
| 聲音環境 | 配音混音/原生音訊平台 | 環境音清單（風吹樹葉/遠處市聲）——ai-voiceover 混音與 Veo/Vidu 原生音訊都吃 |
| 情緒功能 | 編劇/分鏡 | 這場景在情緒弧的哪個位置、負責什麼（蓄力/釋放/留白） |
| 守恆閥紀錄 | 編劇 | 在此場景開了幾個謎、關了幾個謎（謎題守恆，防伏筆斷線） |
| English tokens | 生圖 | 5-8 個高訊號 token |
| 參考圖/最佳平台 | 生圖 | 同角色卡 |

## 三、世界觀卡欄位（novel-analysis 五鏡頭語彙）

| 欄位 | 說明 |
|---|---|
| 一句話系列軸 | 這個世界/系列在演什麼（一句） |
| 造世第一因 | 宇宙論/社會契約/超自然規則的根源——誰定的、為什麼 |
| 稀缺與代價 | 這世界最稀缺的是什麼；獲得力量的代價。沒有代價的力量會讓世界失重 |
| 禁令（不可能三角） | 這世界絕不允許的事——說得出禁令，世界才有骨架 |
| 冰山留白 | 明說了多少、藏了多少；藏的部分要撐得起說出來的部分 |
| 核心命題 | 故事真正在辯的一句可證偽主張（不是「愛很重要」這種廢話）＋反題立場 |
| 經典錨 | 呼應的古典文本/神話/歷史，逐集/逐段列 |
| 美術基調 | 色彩主調、風格錨、規格（比例/時長/配樂調性）——全系列鎖死的製作規格 |
| 🔒 封存區指標 | 結局錨/未爆伏筆**只放檔案路徑**（如系列聖經），不抄內容進卡 |

## 四、匯出對照

> 以下匯出目標除 emotion-shot-pipeline 外皆為外部工具（作者自家的 nine-grid-storyboard / ai-voiceover，以及第三方 ai-media-generator 的 asset-library 格式），不隨本庫附；指令與路徑是那些工具內的寫法，換成你自己的即可。

### → emotion-shot-pipeline `characters/<名>.json`

這張表已寫成程式：`python scripts/bible.py export <角色卡.md> -o <專案>/characters/<名>.json`。缺任何必填欄會報錯、不寫檔；值裡的「（預設，可改）」標記會自動拿掉。

| json 欄（8 必填） | 取自卡 |
|---|---|
| name | 檔名（= 基本·名字的短名） |
| age | 基本·年齡 |
| relations | 敘事層·關係網（保持 dict） |
| background | 敘事層·背景故事 |
| personality | 敘事層·性格（可併入語氣人設一句） |
| appearance | 視覺層·外貌（整段） |
| narrative_function | 基本·敘事功能 |
| arc | 敘事層·弧線 |
| appearance_note（慣例） | 視覺層·appearance_note |

### → nine-grid-storyboard 角色×風格聖經

視覺層整段（外貌＋角色鎖逐字句＋色票/風格錨）＋參考圖路徑與各平台鎖臉指令。**敘事層不要進聖經**（分鏡 prompt 不需要背景故事）。

### → ai-voiceover 參數列

```
# 作者自家 ai-voiceover 工具的呼叫方式（不在本 repo），換成你的 TTS 指令
python scripts/tts.py --file 旁白.txt --voice <voice> --rate=<base_rate> --pitch=<base_pitch> --out 角色_旁白.mp3
# 有情緒譜就改走 tts_expressive.py；混音帶卡上的 mix.py 慣用旗標
# 先用唸法校正表把旁白稿的破音字/數字改寫完再送
```

### → ai-media-generator asset-library 格式

`@角色名`＋視覺錨 bullet＋English tokens code block＋最佳平台——與該檔既有卡片同格式。若該角色已在 asset-library 有舊卡，以本庫為準更新它。
